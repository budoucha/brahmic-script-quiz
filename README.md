# Brahmic Script Quiz

短文の字面から、使われているブラーフミー系文字を当てるブラウザクイズ。

## 収録文字

- デーヴァナーガリー、ベンガル文字、グルムキー文字、グジャラート文字、オディア文字
- タミル文字、テルグ文字、カンナダ文字、マラヤーラム文字、シンハラ文字
- タイ文字、ラオ文字、クメール文字、ビルマ文字、チベット文字
- ジャワ文字、バリ文字

各文字体系に5文を収録し、出題ごとにランダム表示する。不正解時には、選んだ文字と正解の文字の例文・判別ポイントを並べて比較できる。

## 使い方

`index.html` をブラウザで開くだけで動作する。ビルドや外部ライブラリは不要。

キーボードでは `1`〜`6` で回答、回答後は `N` で次の問題へ進める。

## GitHub Pages

リポジトリの **Settings → Pages** で、**Deploy from a branch**、ブランチ **main / (root)** を選ぶと公開できる。
